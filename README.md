# Evil Capture Portal - MyMercer Lookalike 
*for CYS 305 Physical Demonstration of the Hak5 Wifi Pineapple*

## Overview
This project is an **educational-only** evil capture portal designed to resemble the MyMercer landing page (Mercer University student dashboard). It was created specifically for a **physical demonstration** using the Hak5 WiFi Pineapple to showcase the risks of unsecured WiFi networks and phishing techniques.

## Disclaimer
This project is intended **solely for ethical and educational purposes**. It must **not** be used for malicious activities, unauthorized access, or illegal purposes. The author assumes no responsibility for any misuse.

## Features
- Mimics the MyMercer login page to demonstrate phishing risks.
- Uses **PHP, HTML, and CSS**, despite no prior experience in these languages.
- References heavily from the real MyMercer page while incorporating **custom assets** to distinguish it from the legitimate site.
- Captures login credentials (for demonstration purposes only).
- Can be deployed on a Hak5 WiFi Pineapple for real-world security awareness training.

## Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/your-repo/evil-capture-portal.git
2. Deploy the files to a web server (e.g., Apache, Nginx, or WiFi Pineapple).
3. Ensure PHP is enabled on the server.
4. Direct test users to the portal over a controlled test network.
5. Analyze the captured credentials (if any) to demonstrate the risks of phishing.

## Customization

- Replace custom assets if necessary to further distinguish from the real MyMercer page.
- Edit index.php to modify how credentials are logged (for educational analysis only).
